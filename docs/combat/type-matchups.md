# Type matchup reference

The index contains 120 type combinations from the pinned community snapshot. Search by a single type or by a combined key. Where a creature form's type key matches exactly, its detail view also displays the listed weaknesses and resistances.

## What the table means

The values are transcribed matchup fields. They are not a damage calculation. The table does not model move strength, energy, priority, weather, team effects, status, turn order, or encounter-specific rules. A missing row means the snapshot had no matching key, not that the game treats the combination as neutral or immune.
