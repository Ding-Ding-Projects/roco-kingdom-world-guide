# Skills, learnsets, and evolution paths

## Skill groups

Creature details can include a feature skill, native learnset, bloodline skills, and skill-stone entries. Linked skill records show every field supplied by the pinned snapshot, including names, type, category, energy, and descriptions. Handbook topics associated with skill stones are listed separately. A missing description does not mean that the game has no description or that the skill is disabled.

## Evolution data

The source can contain several path records for one local form. Each expandable path displays its chain and any recorded type, level, condition, leader branch, or item. Keep the source wording intact. The table is a community transcription and may not reflect a later patch. Confirm live requirements in the current client before consuming a limited item.

## Historical training sample

The separate S3 sample is not loaded with the initial page data. Opening the detail disclosure fetches it once. Its counts are historical community submissions from S3 season 铅字幻梦. They are not official rankings, win rates, or current recommendations. Use the sample to find questions to investigate, then compare the choices with current skill text and recent official notices.
