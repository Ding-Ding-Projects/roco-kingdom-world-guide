# Habitat labels and linked forms

The habitat index contains 57 exact phrases from the pinned handbook snapshot. Each phrase links to the local form records associated with that source handbook entry. The guide preserves the source wording rather than translating uncertain place names into guessed locations.

## Search and use

Search by the original label or creature name. Expand a result to review its linked form rows. Select a row to open the full Dex detail, including its source list fields and any exact-key joined skills, handbook tasks, evolution details, affinity, ecology, and matchup record.

## Evidence limit

A habitat phrase is a community source field. It does not establish precise coordinates, unlock order, current spawn timing, probability, weather, or Season 4 availability. Use it as a lookup lead, then check the current game map and in-game encounter conditions. The label count measures unique source phrases, not locations or spawn nodes.
