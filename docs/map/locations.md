# Location names and map coverage

## Included reference groups

The local index stores 40 Magic Source labels and three Eternal Night labels from an S3 community index. It also groups 57 habitat phrases from a dated handbook snapshot and three handbook index areas. Chinese source names are preserved because a verified official English place-name set was not found.

The S3 map page displayed an update date of 2026-08-26; its mirror manifest was generated 2026-08-28. The joined handbook snapshot is version `s4-2026-09-24`, pinned to commit `71eba6e4cd5e0f01a5cda60ec5560f58aae2a1c2`.

## What this atlas does

Search place labels, habitat phrases, or creature names. Expand a habitat or handbook area to see linked form rows. Open a row to read its record, sources, and other joined details. The counts in each group describe linked index records, not geographic area size or spawn probability.

## What it cannot prove

The local files contain no coordinates, polygons, route lines, map tiles, point IDs, or third-party marker records. The source labels do not prove S4 availability, travel prerequisites, encounter time, weather, spawn rate, or completeness. The source index is a name lookup, not a live route map.

For coordinates and layers, open the external [Roco Kingdom World map](https://rocokingdomworld.org/maps/). Its homepage reported 7,148 points across seven categories when checked on 2026-09-25. This is the viewer's own count, not an audited total. Its reuse license was not identified, so the local guide links to it without redistributing its marker data or imagery.

## Season 4

The [official Season 4 announcement](https://www.taptap.cn/moment/847022426351994538?group_id=228326) confirms the Moon surface as a seasonal destination. It does not publish a full coordinate atlas or unlock table. Follow the current season assignment and in-game map prompts for access.
